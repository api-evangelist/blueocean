BlueOcean is a Context AI platform purpose-built for marketing teams. Its agentic AI framework, Spark, combines brand, market, product, and customer context to help marketers unlock creativity, accelerate go-to-market, and deliver measurable impact — automating work from strategy through content creation, competitive intelligence, brand performance analytics, and reporting. The platform surfaces evidence-grounded recommendations across brand, product marketing, and content, and is used by enterprise marketing teams at companies such as SAP, AWS, and Cisco. BlueOcean is backed by Insight Partners. BlueOcean publishes no developer program, no API documentation and no pricing; the only machine-readable contract on its estate is the framework-generated OpenAPI its own web application calls.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for BlueOcean: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
